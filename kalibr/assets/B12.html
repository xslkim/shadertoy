动手 ①：装好 Kalibr
Kalibr 基于 ROS，强烈建议用官方 Docker，省去依赖地狱
# 1. 拉取源码
git clone https://github.com/ethz-asl/kalibr
# 2. 构建镜像（选对应 ROS / Ubuntu 版本）
docker build -t kalibr \
  -f kalibr/Dockerfile_ros1_20_04 kalibr
# 3. 进入容器，挂载数据目录
docker run -it -v $(pwd)/data:/data \
  kalibr
🐳 为什么用 Docker
ROS + Python2/3 + ceres 依赖复杂，镜像里都配好了
📂 -v 挂载
把存放 rosbag 和结果的目录映射进容器
✅ 验证
kalibr_calibrate_cameras --help
