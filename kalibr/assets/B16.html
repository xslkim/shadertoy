动手 ③：跑标定命令
一条命令，把多相机内参、畸变、相机间外参一次性解出来
kalibr_calibrate_cameras \
  --bag calib.bag \          # 录好的数据包
  --topics /cam0/image_raw /cam1/image_raw \ # 每个相机话题
  --models pinhole-equi pinhole-equi \  # 每相机畸变模型
  --target aprilgrid.yaml     # 标定板描述
⚠ topics 与 models 顺序一一对应
第 i 个 topic 用第 i 个 model
📄 产物
camchain-….yaml ＋ report-cam-….pdf
🔁 接力初值
先各自估内参 → 再联合优化外参
