## 四、其他发现

1. **轮廓**：高窄圆锥、顶收尖，高宽比与参考一致；轮生"手臂"分层可读。✅
2. **主干表现**：中心 leader 透冠可见（暗红竖线），与参考一致，是加分项；底部裸干暖棕。✅
3. **配色结构**：整体明度分布偏亮、偏平，缺参考"深墨绿为底、亮青绿点缀垫顶"的强对比（详见 ② 定量）。
4. **FBX**：文件存在，1.25 MB，合法 Binary FBX 7.4（文件头校验通过）。⚠️ 本机 ufbx Python 绑定解析该文件时进程崩溃（0xC0000005），未能取得网格/材质统计——可能是绑定兼容性问题，建议发布前用 Blender 导入复检一次。

## 五、遗留问题（按严重度，可执行建议）

1. **【中-高】垫面碎屑化**：将共面平铺比例由 55% 提至 ~75-80%，或按垫分组使碎片共享基准平面、仅加小角度（±10°）扰动；限制垫内卡片随机翻转/滚转角，碎屑感应只出现在垫缘作为流苏。
2. **【中】双色/暗部不足**：目标暗部（v<90）占冠层 45~55%；垫底面统一压至深墨绿，顶面亮青绿，加大顶底明度差（参考中位明度 81~93，当前 103）。
3. **【中-低】轮廓伪影三处**：(a) 近轮廓卡片的侧视板条纹——对接近剪影边界的卡片做朝向约束或剔除极端 edge-on 卡片；(b) 垫缘下垂的"脱离"针叶条——缩短其长度或贴附枝轴、或改为从主干生出的裸枝形态（参考有先例）；(c) 顶部零散裸卡——加密顶部收尖处的卡片密度。

## 六、总体意见

v3.3 的修复方向全部正确：蛋糕环层未复发、干色达标、须边光晕消除、垫面平铺开始生效，主干透冠与暖色干均为加分项。相似度由 70% 升至约 75%，判 **PASS_WITH_ISSUES**。距离参考的最后差距集中在"垫面完整度"与"暗部质量感"两点——二者本质是同一个问题：垫还不够像"一整片羽状厚垫"。建议下一轮集中处理第五节第 1、2 条，轮廓伪影（第 3 条）可同轮顺带修复。
