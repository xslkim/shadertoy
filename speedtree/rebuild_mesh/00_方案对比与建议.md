# 风格化树木自动建模方案对比与总结

> 目标：程序化生成 IL3DN 风格的卡通树（细长主干 + 少量下部枯枝 + 叶卡片簇树冠），
> 复用 `IL3DN_Leaf_01.png` / `IL3DN_Bark_Pine.png` 贴图，可参数化泛化出不同形状但风格统一的树。
>
> 本文件为 5 份分方案调研报告的汇总，详细内容见各分报告。

## 一、关键事实（调研中实测确认）

1. **贴图约定**：`IL3DN_Leaf_01.png` 的 RGB 近白色，叶子形状全部在 **alpha 通道**（不透明约 31%）；颜色由着色端（顶点色/材质色）赋予。这意味着"换色不动贴图"，风格统一的关键在配色参数与卡片分布统计，而非贴图本身。
2. **母体结构友好**：Birch_02 的 Leaves_LOD0 是 2100 张离散 4 顶点 quad 卡（连通分量 100% 可识别），UV 仅 4 角点整幅采样；Branch 为全四边形规则拓扑，位移场形变不会破面。
3. **本机环境已就绪**：Blender 4.2.16 LTS + blender-mcp（插件 v1.2 + pip 包 1.6.4）齐备；Python 3.12 + numpy 可用；项目历史上已有纯 Python 生成 FBX + ufbx 校验的成功经验。
4. **AI 直出不可行**：截至 2026-08，所有主流 AI 3D 模型（Hunyuan3D / TRELLIS / Tripo / Meshy / Rodin）均基于隐式场表面提取，输出必然是实心网格 + 烘焙贴图——叶冠会变成"实心绿坨"，且无法强制使用指定贴图。
5. **风格出处已定位**：`IL3DN_` 前缀资产出自 Unity Asset Store 的 **The Illustrated Nature**（Artkovski，$40，Built-in 管线）。花 $40 可获得同族全部树种作为变体母体池。

## 三、各方案要点摘录

### ① Blender + MCP（详见 [01_blender_mcp.md](01_blender_mcp.md)）
- 已实测跑通：`blender_tree_gen.py` 生成并导出 `output/stylized_tree_seed7.fbx`（两贴图 packed、900 张叶卡片 UV/顶点色齐全）。
- 生产模式：交互调参走 blender-mcp（execute_code + 截图闭环）；批量生产走无头 CLI `blender -b --python blender_tree_gen.py -- --seed N --count M`。
- 注意：Sapling 在 Blender 4.2 已移出内置，需从扩展平台联网安装；MTree v5 本机已装可作后备骨架方案。

### ② 手写代码（详见 [02_manual_code.md](02_manual_code.md)）
- 已实测跑通：`procedural_tree.py`（纯 Python + numpy，CLI 支持 `--seed/--height/--cards`）生成 `sample_tree.obj`（673 quads）+ 软渲染预览 `sample_preview.png` 确认风格。
- 骨架选递归分枝：`crown_start` 单参数切分"下部光秃 / 顶部爆冠"，参数直接映射美术语言。
- 落地 Unity 推荐把同一套 `generate()` 平移为 C# Editor 脚本直写 Mesh（顶点色/subMesh/LOD/风数据无损）。

### ③ 开源库（详见 [03_open_source.md](03_open_source.md)）
- Top3：Sapling Tree Gen（GPL、官方维护、white_birch 预设与参考同源）→ proctree.js（BSD、法律风险最低、输出天然分枝干+twig 卡片两套流）→ friggog/tree-gen（Weber-Penn 骨架质量最好，注意禁售条款）。
- 共性短板："叶簇化"必须自研；双色调平涂属着色器范畴，与生成器解耦。
- 排除：MTree（2021 停更）、Unity Tree Creator（无脚本 API）、The Grove（EULA 禁售产出）、Arbaro/ngPlant（化石级）。

### ④ AI 模型（详见 [04_ai_models.md](04_ai_models.md)）
- 直出整树 ★☆☆☆☆；唯一可行是 **A1 混合管线**：AI 出树干 → 程序化挂叶卡片（与学术界 HourglassTree / Tree-D Fusion 方向一致）。
- 本地候选：Hunyuan3D-2.1（注意许可排除 EU/UK/韩国）、TRELLIS.2；云 API 成本非瓶颈。

### ⑤ 其他（详见 [05_other.md](05_other.md)）
- **FBX 母体变体繁衍**：读→改→写→验闭环此前已在项目跑通；树干弯曲/扭转/锥度位移场 + 叶卡 L1 抖动 / L2 簇级增删 / L3 包络重排布三档；LOD 链同种子变换。
- $40 买 The Illustrated Nature 整包 = 最便宜的风格统一母体池扩充。
- SpeedTree / Houdini / The Grove 对本目标均为风格+成本双错配；Impostor 是远景放大器而非替代（Amplify Impostors $60）。

## 四、最终建议

**推荐组合管线（按优先级）**：

1. **主线：纯 bpy 程序化生成（方案①）**——本机环境已就绪、原型已跑通、风格/泛化/自动化三项全满，且与项目既有 Blender 自动化工具体系零摩擦。
2. **快速扩充：FBX 母体变体繁衍（方案⑤）**——第一批"看起来就正确"的树可从 Birch_02 直接繁衍，成本最低、风格零风险；注意分发授权边界。
3. **量产落地：核心 `generate()` 平移为 Unity C# Editor 脚本（方案②）**——消除 DCC 依赖，顶点色/LOD/风数据原生写入。
4. **可选增强**：树干骨架引入 Sapling/tree-gen 预设（方案③）丰富形态多样性；远景用 Impostor。
5. **暂不采用**：AI 直出整树；如未来想提升树干形态多样性，再评估"AI 出树干 + 程序化挂叶"混合管线。
