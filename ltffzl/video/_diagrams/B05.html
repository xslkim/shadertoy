可重复的随机：哈希函数
同样的输入，永远得到同样的输出 —— 画面才不会每帧乱闪
输入一个编号
p = 12.0
→
fract · dot 位混合
打散成混乱的小数
→
三个伪随机数
n.x n.y n.z ∈ 0~1
// from Dave Hoskins — 一个数 → 三个 0~1 的伪随机数 vec3 N13(float p) { vec3 p3 = fract(vec3(p) * vec3(.1031, .11369, .13787)); p3 += dot(p3, p3.yzx + 19.19); return fract((p3.xxy + p3.yzz) * p3.zyx); }
