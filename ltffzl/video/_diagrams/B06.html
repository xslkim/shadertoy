静态水珠：格子里的小圆点
把画面切成密网格，每格用哈希丢一颗水珠
① 切网格
uv *= 40. 把画面分成密密的格子
② 每格丢一颗
用哈希给每格一个随机位置，只在自己格内
③ 距离场画圆
S(.3, 0., d) 离中心越近越亮 → 圆形水珠
④ 随时间淡入淡出
三角波 Saw 让水珠慢慢冒出、再淡掉
vec2 id = floor(uv); uv = fract(uv) - .5; // 格子编号 + 格内坐标 vec3 n = N13(id.x*107.45 + id.y*3543.65); // 这一格的随机数 float c = S(.3, 0., length(uv - p)) * Saw(.025, fract(t+n.z)); // 圆 × 淡入淡出
